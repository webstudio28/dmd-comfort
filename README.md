# ДМД Комфорт — 11ty сайт

## Старт

```bash
npm install
npm start
```

Build:

```bash
npm run build
```

## Структура

- `src/_data/` — JSON данни (услуги, проекти, блог, видеа, site config)
- `src/_layouts/` — базов layout
- `src/_includes/` — header, footer, modal, home секции
- `src/assets/css/` — Tailwind source → compiled `styles.css`
- Страници: `/`, `/uslugi/`, `/proekti/`, `/blog/`, `/videa/`, `/za-nas/`, `/kontakti/`, `/obrashtane-na-dograma/`

## Слагове

Български думи с латински букви, напр. `pvc-dograma`, `shtori`, `obrashtane-na-dograma`.
